\subsection{Introduction to Optimization}

\emph{Optimization} seeks to find the "best" solution out of 
all possible solutions, for some measure of "best". To 
do this we must \emph{model} the problem mathematically 
and implement some \emph{algorithm} to find the numerical 
solution to the model. \emph{Solvers} assist us in
implementing the algorithm when it's infeasible to do by hand.
