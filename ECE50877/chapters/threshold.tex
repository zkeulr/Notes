\subsection{Threshold Encryption}

The secret key scheme
proposed previously has two issues, namely:
\begin{itemize}
    \item The dealer knows the secret key
    \item The secret key must be assembled to be used
\end{itemize}

We construct a $t$-out-of-$n$ threshold
cryptosystem for $n$ parties $P_1, ..., P_n$
consisting of three algorithms.
\begin{itemize}
    \item Distributed key generation: A protocol between parties for generating a public
          $pk$ key such that party $P_i$ obtains a private share $s_i$ of the private key $sk$
          corresponding to public key $pk$ (algorithm depends on $t$).
    \item Encryption: An algorithm that takes as input plaintext message $m$, public key $pk$,
          and outputs ciphertext $c$ of $m$ under public key $pk$.
    \item Decryption: A protocol between any $t$ parties $P_{i_1} ,\dots , P_{i_t}$ that on input $c$, private
          shares $s_{i_1} ,/dots , s_{i_t}$ , outputs plaintext $m$.
\end{itemize}
For this scheme, the private key $sk$ remains secret at all times 
unless $t$ or more parties cheat, and no trusted dealer is 
required. Threshold El Gamal Encryption meets this scheme.

\subsection{Multi-party Computation}

Say we have two secret values $x$ and $y$ which are 
secret shared using Shamir's secret sharing scheme. 
We want to compute $z = x + y$ without revealing either 
value. Each party can compute $z_i = x_i + y_i$ and $t$ 
of these shares are sufficient to compute $z$, without 
revealing information about $x$ or $y$ (because only 
$z_i$ is shared with other parties and not $x_i$ or $y_i$).

Interestingly, while addition can be performed locally, 
multiplication requires communication. Since the degree 
of the polynomial becomes $t - 1 + t - 1 = 2t - 2$ and 
thus we need $2t - 1$ shares to reconstruct the 
polynomial obtained by multiplying $x$ and $y$. Since 
we previously specified that no more than $t - 1$ parties 
would collaborate, we cannot perform multiplication
without breaking the assumptions. However, parties 
may engage in a polynomial degree reduction protocol 
to reduce $z$ to degree $t-1$, which can then be 
recovered. It's pretty common behavior for one 
operation to be feasible and another to require collaboration, 
hence fully homomorphic encryption is a difficult problem.
